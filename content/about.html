About root_n_reels

A practical knowledge base for people who run servers.

root_n_reels is a free technical reference for system administrators, infrastructure engineers, DevOps learners and anyone preparing for a Linux or Unix interview. It started as study notes and short videos, and grows into the longer explanation behind each Reel.

What you will find here

  • Linux and RHEL administration: LVM, SELinux, networking, systemd, performance and troubleshooting.
  • Unix: Oracle Solaris (ZFS, Zones, LDOMs) and HP-UX.
  • Infrastructure and DevOps: Nutanix, server hardware, Podman, Ansible Automation Platform.
  • Troubleshooting pages that start from the symptom, cheat sheets you can copy from, and interview questions by topic and level.

How content is written

  • Commands are shown with the reason behind them and, where useful, the expected output.
  • Pages state which versions they cover (for example RHEL 7/8/9 or Solaris 10/11) and when they were last updated.
  • Destructive or disruptive commands carry a visible warning. Always test in a lab first and take a backup or snapshot before changing production.
  • Found a mistake? Open an issue and it will be fixed.

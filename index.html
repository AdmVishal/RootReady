🎯 About This Library

root_n_reels is a comprehensive technical reference library compiled from multiple study guides and interview preparation documents. All content is organized by topic for easy navigation.

  • RHEL — Complete Red Hat Enterprise Linux administration reference covering versions 6 through 9
  • Linux Admin Guide — Practical commands and real-world Q&As for Linux/Unix sysadmin interviews
  • OS Admin L3 Interview — 150+ interview questions covering all major OS platforms at L3 depth
  • Solaris — Oracle Solaris deep dive with SPARC, ZFS, Zones, and enterprise features
  • HP-UX & Common — HP-UX 11i plus cross-platform operations and legacy systems reference
  • ITIL & Unix Ops — ITIL processes mapped to real Unix/Linux operational scenarios
  • CCNA — 31-topic networking study guide from fundamentals through automation
  • Network Reference — Advanced BGP, OSPF, EIGRP and VPN configuration reference
  • Nutanix — HCI foundations, Prism operations, and Nutanix administration
  • Podman Containers — RHCSA RHEL 10 deep dive: 19 topics L1→L3, daemonless/rootless architecture, images, volumes, pods, Quadlet, 8 interview Q&As
  • Server Hardware — HP ProLiant BL/C7000, iLO, Virtual Connect, Dell PowerEdge, iDRAC, racadm, PERC, IBM MegaRAID — 5 scenarios
  • PHC Interview Guide — Product Hardening Compliance Specialist prep: 32 Q&As, 7 scenarios, CIS, Qualys, Wiz, NIST, ISO 27001

🛠️ Troubleshooting Scenarios

Start with the symptom and work toward the root cause.

Filesystem is 100% full

Check filesystem usage, deleted-open files, large directories and inode exhaustion.

Open Linux troubleshooting guide →

Server experiencing high CPU

Inspect load, processes, CPU states and application-level activity.

Review Linux administration →

SSH connection refused

Validate service status, listening ports, firewall rules and network reachability.

Review RHEL reference →

Multipath path failure

Review path state, HBA visibility, storage presentation and multipath configuration.

Review Linux operations →

System is slow but CPU is idle

Investigate memory pressure, I/O wait, storage latency and blocked processes.

Explore performance topics →

Service fails after reboot

Check enablement, dependencies, logs, permissions and configuration validation.
